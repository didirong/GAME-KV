# 遊戲檢查紀錄

檢查日期：2026-10-14。

## 原始版本

- 原始 HTML 約 5.18 MB、479 行，圖片以 Base64 內嵌；程式常把多個敘述擠在同一行。
- 使用 UTF-8 成功解碼，未發現 U+FFFD 取代字元。中文、日文、Emoji 是原始內容，不屬於亂碼。
- 純前端 Canvas 遊戲。沒有 API 呼叫、登入、後端、資料庫或服務端祕密。
- 存在多次覆寫 CSS、固定框尺寸溢出、圖片載入失敗卡住、特效依幀數變快，以及最右邊小遊戲角色超出畫布等問題。
- 部分對話與結局敘述使用不必要的 `<br>`，讓一個句子被硬切成多行。

## 已完成的修改

1. 拆出 HTML、CSS、11 張圖片、角色資料、音效、UI 與存檔模組，統一 Prettier 格式與主要變數命名。
2. 使用本機 DotGothic16 與 Fusion Pixel zh-TW。掃描 HTML／CSS／JavaScript 中的 790 個中文／日文字元，確認都有像素字形；開場等待字體就緒。
3. 主畫面維持原版色彩、海報、HUD 位置與緊湊按鈕。海報等比例縮放；手機橫向可捲動，避免壓縮成難以閱讀的狹小畫面。
4. 修正卡片與手帳寬度、內容捲動、焦點切換、Canvas 與按鈕的觸控行為。
5. 對話改成純文字與自然換行；結局不再把單句拆成三段。
6. 加入儲存格式版本、進度／最高分保存、存檔內容驗證及禁用儲存空間的降級處理。沒有雲端資料傳輸。
7. 圖片載入失敗提供重試；等待所有主要圖片完成解碼後才開始。
8. 背景分頁與視窗暫停遊戲更新；限制全畫布繪圖約 60 fps；特效依時間更新。
9. 新增手帳探索入口與三款小遊戲的鍵盤操作、重新冒險；結局預覽不偽造完成進度。
10. 改用 Fisher–Yates 洗牌、防止店舖切換重疊、讓七位小遊戲角色都位於畫布內、避免滑動造成誤點。
11. 圖片以無損 WebP 提供：原圖合計 3,828,986 bytes，轉換後 3,033,998 bytes；解碼像素比對相同。字體另外提供，整包大小也包含它們。

## 驗證限制與發佈前驗收

此次不是所有實體裝置的相容性認證。瀏覽器視窗尺寸測試不代表已在 iPhone、Android 與每個瀏覽器實測。仍需在以下實機確認：

- iPhone Safari：音樂在點開始後能播、旋轉與安全區、觸控拖曳、背景切換後恢復。
- Android Chrome：拖曳籃子、長時間遊戲、三款小遊戲結果、存檔恢復。
- 桌機 Chrome、Firefox、Safari：鍵盤操作、音訊、捲動視窗與結局。
- 實際 GitHub Pages 網址：子路徑資源、HTTPS、首次字體載入與重新整理。
- 螢幕閱讀器和縮放需求：目前有焦點管理、名稱與替代探索入口，但未完成完整無障礙稽核；Canvas 畫面本身仍以視覺遊玩為主。

本版針對支援 CSS container query units、dynamic viewport、ES modules、inert 與 WebP 的現代瀏覽器。沒有為已停止維護的舊瀏覽器提供 polyfill。若後續加入排行榜、帳號、共用存檔或多人模式，需另設後端與相應測試，不能把 localStorage 成績當作可信服務端資料。

## 第二次版面與動畫修正

依使用者提供的 52 秒錄影與三張截圖再次比對：

- 載入頁恢復角色隊伍移動、像素跳動與提示輪播；角色保持隊形，開始按鈕預留空間，提示區固定高度，不再在完成載入時推動標題。
- 載入百分比包含圖片解碼與兩套像素字體，視覺進度平滑前進，資源完成且開場動畫完成才顯示 START。
- 結局團員採用固定 24cqw 圖片欄、4cqw 間距與一致文字欄；角色名字、稱號與介紹皆對齊同一條左邊界。
- 行程日期與地點分成固定兩欄，成績也改成欄位排版，避免字數影響每一行的位置。
- 字幕依內容高度計算滾動距離，播完停留最後一幕；提供暫停、續播、重播。位移使用 cqw，縮放與旋轉時沿用海報比例。
- 音量按鈕改用 16×16 像素 SVG，不再使用系統的立體 Emoji。
- 19 項測試通過，包括新增的載入動畫、字幕控制和音量圖示回歸檢查。瀏覽器亦測量了團員、日期、地點各欄的左邊界，確認逐列一致。

字幕播完時，若本機進度成功保存，最後的文字更新為「回憶存檔完成。」並填滿像素進度格；若儲存空間不可用，顯示祝福文字，避免錯誤宣稱已保存。
